# Claude Basics

This folder contains notebooks and helper files for learning the Anthropic API. The examples cover prompting, tool use, streaming, caching, document processing, images, and evaluations.

## Setup

Complete the setup in the root `README.md` first. Run all commands below from the repository root.

## Run the basic Python example

```bash
uv run python -m claude_basics.main
```

## Run the notebooks

Open the repository in an editor that supports Jupyter notebooks. Select the Python interpreter inside the project:

```text
.venv/bin/python
```

Then open any `.ipynb` file in this folder and run its cells.
